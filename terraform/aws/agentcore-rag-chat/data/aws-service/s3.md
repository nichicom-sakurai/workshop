# Amazon S3 (Simple Storage Service)

Amazon S3 is object storage that stores data as objects inside buckets.

## Key concepts

- **Bucket**: A globally named container for objects. Bucket names must be globally unique.
- **Object**: A file plus metadata, identified by a key within a bucket.
- **Storage classes**: S3 Standard, S3 Standard-IA, S3 One Zone-IA, S3 Glacier Instant Retrieval, S3 Glacier Flexible Retrieval, and S3 Glacier Deep Archive trade off retrieval speed against cost.
- **Versioning**: Keeps multiple variants of an object so deletions and overwrites are recoverable.
- **Lifecycle rules**: Automatically transition objects to cheaper storage classes or expire them.

## Security

- Block Public Access settings prevent objects from being made public.
- Bucket policies and IAM policies control who can read and write objects.
- Server-side encryption (SSE-S3, SSE-KMS) encrypts objects at rest.

## S3 Vectors

S3 Vectors is a vector storage capability used by Amazon Bedrock Knowledge Bases to store and query embeddings without running a separate vector database.
